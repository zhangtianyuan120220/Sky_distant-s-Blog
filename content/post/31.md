## 问题理解
给定一个由字符 `a` 和 `b` 组成的字符串，例如 `ababba`。  
每次操作可以交换相邻的两个字符。  
目标是使得**同一种字母**全部连续排在一起（中间不夹杂另一种字母）。  

允许另一种字母位于两侧，例如：
- `aaaabbb`（所有 `a` 连续）
- `bbbaaabb`（所有 `a` 连续，`b` 分布在两侧）
- `bbbaaaa`（所有 `a` 连续，`b` 全部在左侧）

---

## 核心思路
### 1. 两种选择
我们可以选择：
- 让所有 `a` 连续
- 让所有 `b` 连续

取两种方案中花费较少的那个。

### 2. 计算花费的方法
假设我们要让所有 `a` 连续。  

记 $k$ 为 `a` 的数量，设它们最终占据 $k$ 个连续的位置：  
$$
L, L+1, \dots, L+k-1
$$

将原字符串中第 $i$ 个 `a`（从左到右，$i$ 从 $0$ 开始）放在位置 $L+i$ 上。  
若该 `a` 在原字符串中的位置为 $p_i$，则移动距离为：
$$
|p_i - (L + i)|
$$

总花费为：
$$
\sum_{i=0}^{k-1} |p_i - i - L|
$$

### 3. 最优 $L$ 的选取
这是一个经典的**一维选址问题**。  
令 $d_i = p_i - i$，则总花费为：
$$
\sum_{i=0}^{k-1} |d_i - L|
$$
当 $L$ 取 $\{d_i\}$ 的中位数时，该和最小。

---

### 4. 算法步骤
1. 统计字符串中 `a` 与 `b` 的个数
2. 若某种字母数量 $\le 1$，则让其连续的花费为 $0$
3. 否则：
   - **对于 `a`**：
     - 记录所有 `a` 的位置 $p_0, p_1, \dots, p_{k-1}$
     - 计算 $d_i = p_i - i$
     - 取 $\{d_i\}$ 的中位数 $L$
     - 计算 $\sum_{i=0}^{k-1} |d_i - L|$ 即为花费
   - **对于 `b`**：同理
4. 答案 $= \min(\text{cost}_a, \text{cost}_b)$

---

## 例子
字符串：`bababa`

- **让 `a` 连续**：
  - `a` 的位置（0‑based）：$1, 3, 5$
  - $d_i = [1-0, 3-1, 5-2] = [1, 2, 3]$
  - 中位数 $L = 2$
  - 花费 $= |1-2| + |2-2| + |3-2| = 2$

- **让 `b` 连续**：
  - `b` 的位置：$0, 2, 4$
  - $d_i = [0-0, 2-1, 4-2] = [0, 1, 2]$
  - 中位数 $L = 1$
  - 花费 $= |0-1| + |1-1| + |2-1| = 2$

答案为 $\min(2, 2) = 2$。

---

## 为什么这是最优的？
在相邻交换中，每个字符移动的次数至少是其到目标位置的曼哈顿距离。  
上述方法通过选择合适的目标起点 $L$（中位数）最小化了总移动距离，且每一步交换都可以实现该移动方案。

---

## 最终答案
分别计算“聚 `a`”和“聚 `b`”的最小交换次数，取较小值即可。

**时间复杂度**：$O(n)$（只需遍历一次统计位置，再线性时间求中位数）  
**空间复杂度**：$O(n)$（存储位置数组）

## 代码解决
```cpp
#include <bits/stdc++.h>
using namespace std;
// 计算让某种字符连续的最小交换次数
long long solve(vector<int>& awa,int count) {
    if(count<=1) return 0;  // 0个或1个字符已经是连续的
    vector<long long> qwq(count);
    // 计算差值：位置 - 序号
    for(int i=0;i<count;i++){
        qwq[i]=awa[i]-i;
    }
    // 找中位数（部分排序）
    nth_element(qwq.begin(),qwq.begin()+count/2,qwq.end());
    long long best=qwq[count/2];  // 最好的起始位置
    // 计算总距离
    long long cost=0;
    for (int i=0;i<count;i++) {
        long long ans=best+i;  // 目标位置
        cost+=abs(awa[i]-ans);
    }
    return cost;
}
int main(){
    int t;
    cin>>t;
    while(t--){
        int n;
        string s;
        cin>>n>>s; 
        vector<int> aawa,bawa;
        // 记录每个字符的位置
        for(int i=0;i<n;i++){
            if(s[i]=='a') {
                aawa.push_back(i);
            }
			else{
                bawa.push_back(i);
            }
        }
        // 计算两种方案的花费
        long long costA=solve(aawa,aawa.size());
        long long costB=solve(bawa,bawa.size());
        // 取较小的
        cout<<min(costA,costB)<<endl;
    }
    return 0;
}//Sky_distant
