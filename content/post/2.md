## 题目分析
- 这道题好像其他大手子都是用平均数算的，我用另一种思路来解决这道题。
- 将这道题看作物理题，那么它就是杠杆问题，设想有一根轻质的杠杆，不计它的重力，在杠杆上有一个数轴，数轴上的每一个刻度表示一个难度。
- 刻度 s 就是已解决问题的平均难度，在刻度 $s$ 挂了 $k$ 个钩码；刻度 $ans$ 就是剩余难度的平均难度，在刻度 $ans$ 挂了 $n-k$ 个钩码，所有题的平均难道为 $d$ 就是整个杠杆的支点。
- 根据杠杆原理：$l1 \times F1 = l2 \times F2$，就能够得到答案 $k \times ( d - s ) = ( n - k ) \times (ans - d)$。
- 但是当 $ans < 0$ 或 $ans > 100$ 时，不符合题目要求就应该输出 `impossible`。

## 代码实现
```cpp
#include<bits/stdc++.h>
#define ll long long
#define ld long double

using namespace std;
ld n,k,d,s;
ld ans;
int main() {
	cin>>n>>k>>d>>s;
	ans=d+(k*1.0*(d-s))*1.0/(n-k)*1.0;
	if(ans<0.0||ans>100.0){
		puts("impossible");
	}
	else cout<<fixed<<setprecision(7)<<ans<<endl;
    return 0;
}
