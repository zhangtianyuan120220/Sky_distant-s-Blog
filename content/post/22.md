## 题目分析
- 给定一个长度为 $n$ 的数组 $a$，你可以选择**一个整数** $x$（可以为负），对数组所有元素同时加上 $x$（只允许操作一次）。操作后，求数组的最大可能 $\operatorname{MEX}$ 值。
- $\operatorname{MEX}$ 定义为最小的没有出现在数组中的非负整数。
- 设选择偏移量 $x$，则新数组为：$b_i=a_i+x$ 而我们要最大化 $\operatorname{MEX}(b)$。
- 读入数组，统计每个值的出现次数（用于检查排除性）。
- 获取去重排序后的数组。
- 从大到小枚举可能的 $\operatorname{MEX}$ 值 $m$。
- 对每个 $m$，在去重数组中寻找长度为 $m$ 的连续整数段。
   - 检查该段是否连续（相邻差为 `1`）。
   - 设段的最大值为 $t$，检查 $t+1$ 是否不在原数组中。
- 找到第一个满足条件的 $m$ 即为答案。

## 代码解决
```cpp
#include<bits/stdc++.h>
using namespace std;
int n;
void solve(){
    cin>>n;
    vector<int> a(n);
    unordered_map<int,int> cnt;//记录每个元素出现的次数
    for(int i=0;i<n;i++){
        cin>>a[i];
        cnt[a[i]]++;
    }
    // 去重并排序
    set<int> awa(a.begin(), a.end());//拷贝a中原有的数据
    vector<int> qwq(awa.begin(), awa.end());//拷贝awa中去重排序后的数据
    int ans = 0;
    // 从大到小尝试 m
    for (int m=min(n,int(qwq.size()+1));m>=1;m--){
        bool cmp=false;
        // 在去重数组上找长度为 m 的连续段
        for(int i=0;i+m-1<qwq.size();i++){
            bool cmb=true;
            // 检查是否连续
            for(int j=1;j<m;j++){
                if (qwq[i+j]!=qwq[i+j-1]+1){
                    cmb=false;
                    break;
                }
            }
            if(cmb){
                int num=qwq[i+m-1];//最大值t
                if(cnt[num+1]==0){//t+1不在原数组
                    cmp=true;
                    break;
                }
            }
        }
        if(cmp){
            ans=m;
            break;
        }
    }
    cout<<ans<<endl;
}
int main(){
    int t;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
