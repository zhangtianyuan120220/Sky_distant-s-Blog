## 题目分析
- 题目要求我们模拟第一个遇到的人的行为，根据规则：
    - **优先规则**：每个人都想说 `double it`。
    - **约束规则**：如果一个人说了 `double it` 之后，**下一个人要面对的金额**（即 $2x$）**严格大于**（$>d$）预算，那么当前这个人就必须说 `take it`。
- 因此，只需判断 $2x$ 与 $d$ 的大小关系。
- 设当前金额为 $x$，预算为 $d$：
    - 如果 $2\times x\le d$，输出 `double it`。
    - 如果 $2\times x>d$，输出 `take it`。

## 代码实现
```cpp
#include<bits/stdc++.h>
#define ll long long
using namespace std;
ll x,d;
int main(){
    cin>>x>>d;
    if(2*x<=d){
        puts("double it");
    }
    else{
        puts("take it");
    }
    return 0;
}//Sky_distant
