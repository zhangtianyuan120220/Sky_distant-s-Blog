## 题目分析
- 要得到答案，可以一直维护一个当前的第一国家。
- 对于每个输入的国家，以以下规则进行比较：
  - 若该国家金牌数比当前第一国家的金牌数多，那么第一国家就是金牌多的国家。
  - 若金牌数相同，比较银牌数量，第一国家就为银牌数多的那个国家。
  - 若金牌和银牌是数量都相同，比较铜牌数量，第一国家就为铜牌数多的那个国家。

## 代码解决
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,g,s,b;
string ans,name;
int ansg=-1,anss=-1,ansb=-1;
bool cmp;
int main(){
    cin>>n;
    for(int i=0;i<n;i++){
        cin>>g>>s>>b;
        getline(cin>>ws,name);
        cmp=0;
        if(g>ansg){
            cmp=1;
        }
        else if(g==ansg){
            if(s>anss){
                cmp=1;
            }
            else if(s==anss){
                if(b>ansb){
                    cmp=1;
                }
            }
        }
        if(cmp){
            ansg=g;
            anss=s;
            ansb=b;
            ans=name;
        }
    }
    cout<<ans<<endl;
    return 0;
}//Sky_distant
