## 题目分析
- 第一行一个 $n$ 和一个长度为 $n$ 的字符串 $s$。
- 交换最后两个字符。

## 代码解决
```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n;
    string s;
    cin>>n>>s;
    if (n>=2) {
        swap(s[n-2],s[n-1]);
    }
    cout<<s<<endl;
    return 0;
}
