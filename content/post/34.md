## 题目分析

### 题目要求
- 输入一个整数 $n$，整数后跟着 $n$ 行字符 $C_i$，$C_i$ 为 `\` 或 `/`。

- 输出一个整数，表示いろは酱写下的线包含的「く」的数量。
  
### 解题思路
- 使用一个栈，来一个一个存入 $C_i$，$a$ 为栈内 `/` 的个数，$b$ 为栈内 `\` 的个数，$ans$ 为「く」的数量。
- 当 $C_i$ 为 `/` 时，判断此时栈顶是否也是 `/` 如果是，就将其压入栈，否则，判断当前栈内数据是否为一个「く」，是：就让 $ans+1$，否则：$ans$ 不变。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n;
int a=0;//"/"的个数
int b=0;//"\"的个数
int ans=0;//"く"的个数
stack<char> awa;
void clear(){//清空栈的函数
	stack<char> awaclear;
	swap(awa,awaclear);
}
char c[500000];
int main(){
    cin>>n;
    for(int i=1;i<=n;i++){
    	cin>>c[i];	
	}
	if(n==1){//当只有一个字符肯定是不能组成"く"的
		puts("0");
    return 0;
	} 
	awa.push(c[1]);//提前处理第一个数据
	if(c[1]=='/') a++;
	else b++;
	for(int i=2;i<=n+1;i++){
		if(c[i]=='/'){//当c[i]为'/'时
			if(awa.top()=='/'){//如果此时栈顶也是'/'时
				awa.push(c[i]);//将c[i]压入栈
				a++;// '/'数量加1
			}
			else{//栈顶是'\'时
				if(a==b){//如果数量相同，则能组成一个"く"
					ans++;//数量加1
				}
				clear();//将栈清空
				awa.push(c[i]);
				a=b=0;
				a++;			
			}
		}
		if(c[i]=='\\'){//当c[i]为'\'时
			b++;
			awa.push(c[i]);
		}	
	}
	if(a==b){//最后特判如果数量相同
		ans+=1;//数量加1
	}
	cout<<ans<<endl;//输出结果
    return 0;
}
