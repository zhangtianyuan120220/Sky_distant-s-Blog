## 题目理解
- 有 $t$ 组数据。
- 每组数据第一行为 $n$ 表示数组 $a$ 的长度，第二行为数组 $a$。
- 要求在数组 $a$ 中进行**至多一次操作**交换数组中任意两个位置的元素，求最大的 $ans$ 值。
- $ans$ 的计算公式为 $ans=\sum_{i=1}^{n}\operatorname{max}(a_1,\ldots,a_i)$。
- $ans$ 由数组的前缀和决定，通过将大的数从后面调到前面可以增加数组的前缀和这个性质直接写暴力。
- 由于数据量小，时间限制也比较长，可以用暴力枚举来做。

## 代码解决
```cpp
#include<bits/stdc++.h>
using namespace std;
vector<int> a;
int t,n;
int jz(){//计算ans的函数
    int maxx=0;
    int zjz=0;
    for(int x:a){
        maxx=max(maxx,x);
        zjz+=maxx;
    }
    return zjz;
}
inline void solve(){
    a.clear();//多测不清空，爆零两行泪
    cin>>n;
    for(int i=0,b;i<n;i++){
        cin>>b;
        a.push_back(b);
    }
    int ans=jz();//初始时ans的值
    for(int i=0;i<n;i++){
        for(int j=i+1;j<n;j++){
            swap(a[i],a[j]);//先改变顺序
            ans=max(ans,jz());//求ans的值是否比原来的大，是就更新ans值
            swap(a[i],a[j]);//还原回原来数组
        }
    }
    cout<<ans<<endl;
}
int main() {
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}//Sky_distant
