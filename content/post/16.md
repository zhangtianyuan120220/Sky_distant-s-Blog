## 题目分析
- **线性筛**通过 ```if(i%primes[j]==0)break;``` 这一步来减少循环次数，确保：
    - **时间复杂度**：$O(N)$，其中 $N$ 是数据范围上限。
    - **空间复杂度**：$O(N)$，用于存储素数表和标记数组。
- 具体思路：
  1. **预处理**：在读取输入之前，先运行一次线性筛，标记出 $1$ 到 $10^6$ 之间所有的素数，结果存入布尔数组 `cmp`。
  2. **$O(1)$ 查询**：对于每一组输入的 $a$ 和 $b$：
     - 检查 $b-a$ 是否等于 $2$。
     - 检查 $cmp_a$ 和 $cmp_b$ 是否同时为 `true`。
  3. **输出结果**：满足上述两者输出 `Y`，否则输出 `N`。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1000005;
bool cmp[N];
int primes[N];
int cnt=0;
void xxs(int n) {
    fill(cmp,cmp+n+1,true);
    cmp[0]=cmp[1]=0;
    for(int i=2;i<=n;i++){
        if(cmp[i]){
            primes[cnt++]=i;
        }
        for(int j=0;j<cnt&&i*primes[j]<=n;j++){
            cmp[i*primes[j]]=0;
            if(i%primes[j]==0)break;
        }
    }
}
int main(){
    xxs(N);
    int t;
    cin>>t;
    while(t--){
        int a,b;
        cin>>a>>b;
        if(b-a==2&&cmp[a]&&cmp[b]){
            puts("Y");
        }
        else{
            puts("N");
        }
    }
    return 0;
}//Sky_distant
