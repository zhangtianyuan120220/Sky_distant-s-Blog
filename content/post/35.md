
## 2. 分析

- 分针一小时旋转角度：
$$360 °$$
- 分针一分钟旋转角度：
$$360°\div60=6°$$
- 时针一小时旋转角度：
$$360°\div12=30°$$
- 时针一分钟旋转角度：
$$30°\div60=0.5°$$
- 分针与时针一分钟的相对旋转角度：
$$6°-0.5°=5.5°$$

---

再利用小学奥数及初中数学知识可以列出一下方程
 
解：设经过 $x$ 小时，分针与时针重合。

$$ 
30 \times x=6 \times 60 \times x-360 °
$$
解得： $$x= \dfrac{720}{11}$$。

综上所述，每经过 $ \dfrac{720}{11}$ 小时，将会重合一次。

#include<bits/stdc++.h>
using namespace std;
int h1,m1,h2,m2;
int ans;
int main(){
//	freopen("clock.in","r",stdin);

	printf("Initial time  Final time  Passes\n");

		int t1=(h1%12)*60+m1;
		int t2=(h2%12)*60+m2;
		//计算共经过多长时间
        if(t2<t1){
            t2+=720;//如果跨过12点
        }
        ans=(11*t2-1)/720-(11*t1)/720;//算出重合次数
		printf("       %02d:%02d       %02d:%02d %7d\n",h1,m1,h2,m2,ans);
		//输出结果
	}
	printf("End of program 3 by team X\n");//不要忘记输出
	return 0;
}
