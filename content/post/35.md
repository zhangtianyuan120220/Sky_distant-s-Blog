## 1. 题目大意

### 题目描述：

你有一个标准的 $12$ 小时模拟时钟，带有时针和分针。在给定的时间区间内，分针会经过时针多少次？

### 输入：

输入文件包含不定数量的行；每行包含四个数字。
- 第一对数字代表一个“起始时间”；第二对数字代表一个“结束时间”。
- 在每一对数字中，第一个数字代表小时，第二个数字代表分钟。
- 小时的范围是 $1\dots12$，分钟的范围是 $0\dots59$。
- 没有任何起始时间或结束时间会是分针刚好经过时针的那个瞬间。（特别地，“$12:00$”不会作为起始时间或结束时间出现。）
- 起始时间不会与对应的结束时间相同。
- 在起始时间和对应的结束时间之间，时针转动的角度小于完整的一圈（$360$ 度）。
- 当时针从起始位置转动到结束位置时，它可能会、也可能不会扫过钟面上的数字 $12$。
- 如果扫过了，那么要么起始时间是“上午”时间而结束时间是“下午”时间，要么反之。
- 如果没有扫过，那么两个时间（起始和结束）要么都是“上午”，要么都是“下午”。

### 输出：

每行输入产生一行输出，包含：
- 起始时间和结束时间，以及在起始时间和结束时间之间，分针经过时针的次数。

- 请注意所有格式细节，例如大小写字母、标点符号、空格以及没有空行。
- 在每个时间显示中，小时和分钟显示在宽度为 $2$ 的字段中，用冒号分隔。
- 如果十位数字（小时或分钟）为零，则显示为零。

以下是输出格式模板（显示在上述两行输出之间）：
```
Initial time Final time Passes
12345678901234567890123456789012
12:50 01:02 0
```

### 样例输入：
```
12 50  1  2
 3  8  3 20
 2 45 11  0
11  0  3 20
 1  2 12 50
 3 20  3  8
```

### 样例输出：
```
Initial time Final time Passes
       12:50      01:02      0
       03:08      03:20      1
       02:45      11:00      8
       11:00      03:20      4
       01:02      12:50     11
       03:20      03:08     10
```

## 2. 分析

- 分针一小时旋转角度：
$$360 °$$
- 分针一分钟旋转角度：
$$360°\div60=6°$$
- 时针一小时旋转角度：
$$360°\div12=30°$$
- 时针一分钟旋转角度：
$$30°\div60=0.5°$$
- 分针与时针一分钟的相对旋转角度：
$$6°-0.5°=5.5°$$

---

再利用小学奥数及初中数学知识可以列出一下方程
 
解：设经过 $x$ 小时，分针与时针重合。

$$ 
30 \times x=6 \times 60 \times x-360 °
$$
解得： $$x= \dfrac{720}{11}$$。

综上所述，每经过 $ \dfrac{720}{11}$ 小时，将会重合一次。

## 3.代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int h1,m1,h2,m2;
int ans;
int main(){
//	freopen("clock.in","r",stdin);
//	freopen("clock.out","w",stdout);
	printf("Program 3 by team X\n");
	printf("Initial time  Final time  Passes\n");
	while(cin>>h1>>m1>>h2>>m2){
		int t1=(h1%12)*60+m1;
		int t2=(h2%12)*60+m2;
		//计算共经过多长时间
        if(t2<t1){
            t2+=720;//如果跨过12点
        }
        ans=(11*t2-1)/720-(11*t1)/720;//算出重合次数
		printf("       %02d:%02d       %02d:%02d %7d\n",h1,m1,h2,m2,ans);
		//输出结果
	}
	printf("End of program 3 by team X\n");//不要忘记输出
	return 0;
}
```
