## 题目分析
这个问题其实是一个**两数之和**计数问题

1. 遍历每个人的钱数 $a_i$。
2. 需要的另一半是 $m - a_i$。
3. 在集合中查找是否有这样的另一半，且这个另一半出现的时间是在当前朋友之前（避免重复计数同一个对）。
4. 因为每个人的钱不同，所以 $a_i$ 不会和另一个相同值的人混淆。

具体做法：
- 用一个集合 $awa$ 记录已经遍历过的钱数。
- 对于当前钱 $a_i$，计算 $ans = m - a_i$。
- 如果 $ans$ 在 $awa$ 中，说明找到了一对，计数加 $1$。
- 将 $b$ 加入 $awa$。

这样遍历一遍即可得到所有不重复的配对数量。

## 代码
```cpp
#include<bits/stdc++.h>
using namespace std;
void solve(){
	int n,m;
    cin>>n>>m;
    vector<int> a(n);
    for(int i=0;i<n;i++){
        cin>>a[i];
    }
    unordered_set<int> awa;//一种自动去重但不排序的数据结构 
    int qwq=0;
    for(int b:a){
        int ans=m-b;
        if(awa.find(ans)!=awa.end()){//查找有无可以买披萨的组合 
            qwq++;
        }
        awa.insert(b);
    }
    cout<<qwq<<endl;//输出答案 
}
int main(){
    int t;
    cin>>t;
    while(t--){
    	solve();
    }
    return 0;
}
