## 题目分析
- 我们有一个长度为 $n$ 的数组 $a=[a_1,a_2,\ldots,a_n]$，删掉一个元素，得到一个新数组 $b$（长度为 $n-1$）。
- 求 $\sum_{i=1}^{n-2}|b_i-b_{i+1}|$ 的最小值
- 那么通过观察样例可以先求出所有相邻元素的差的绝对值 $awa=\sum_{i=1}^{n-1}|a_i-a_{i+1}|$。
- 删去 $a_k$ 后原来包含 $a_k$ 的 $|a_k-a_{k+1}|$ 和 $|a_{k-1}-a_{k}|$ 将被删去，新加入了 $|a_{k-1} -a_{k+1}|$，那么结果就等于 $awa-|a_k-a_{k+1}|-|a_{k-1}-a_{k}|+|a_{k-1} -a_{k+1}|$。
- 但是当 $k=1$ 时结果是 $awa-|a_1-a_2|$ 和当 $k=n$ 时结果是 $awa-|a_{n-1}-a_n|$，需要特判掉这两种情况。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int t;
int main(){
    cin>>t;
    while(t--){
        int n;
        int awa=0;
        int ans;
        cin>>n;
        vector<int> a(n+10);
        for(int i=0;i<n;i++){
            cin>>a[i];
        }
        for(int i=0;i<n-1;i++){
            awa+=abs(a[i]-a[i+1]);//求总和 
    	}
    	//计算答案 
        ans=awa;
        ans=min(ans,awa-abs(a[0]-a[1]));
        ans=min(ans,awa-abs(a[n-2]-a[n-1]));
        for(int k=1;k<n-1;k++){
            ans=min(ans,awa-abs(a[k-1]-a[k])-abs(a[k]-a[k+1])+abs(a[k-1]-a[k+1]));
        }
        cout<<ans<<endl;
	}
    return 0;
}//Sky_distant
