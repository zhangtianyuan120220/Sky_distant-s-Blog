## 题目分析
- 我们要开车从起点到终点，中途有若干个加油站，每个加油站的油价不同，我们要使用最少的钱到达终点。
- 第一行有五个实数，第一个实数 $S$ 表示起点到终点的距离，第二个实数 $C$ 表示油箱的容量，第三个实数 $L$ 表示每升油能行驶的距离，第四个实数 $P_0$ 表示起点的油价，第五个整数 $N$ 表示加油站的数量。接下来 $N$ 行，每行有两个实数，第一个实数 $D_i$ 表示第 $i$ 个加油站到起点的距离，第二个实数 $P_i$ 表示第 $i$ 个加油站的油价。
- 我们可以先特判一下，如果有相邻的加油站，即使加满油也到不了的话，肯定无解，直接输出 `No Solution`。
- 将起点看作第一个加油站，油价为 $P_0$，距离为 $0$，终点为第 $N+1$ 个加油站，距离为 $S$，油价为 $0$。
- 每次加油时的策略：
    - 如果下一个加油站的油价比当前加油站便宜，那么我们就在当前加油站买刚好够到下一个加油站的油。
    - 否则我们就在当前加油站加满油，然后去可以到达加油站中油价最便宜的那个加油站。
- 注意特殊情况：当 $S=0$ 时，不需要花钱，输出 `0.00`，当 $N=0$ 时，只能在起点加油。

## 代码实现
```cpp
#include<bits/stdc++.h>
#define ll long long
#define up(i,a,b,c) for(ll i=a;i<=b;i+=c)
#define dn(i,a,b,c) for(ll i=a;i>=b;i-=c)
using namespace std;
double s,c,l,num=0,ans=0;//num为剩余当前油量，ans为总花费
ll n;
double p[10],d[10];
int main(){
    cin>>s>>c>>l>>p[0]>>n;
    up(i,1,n,1){
        cin>>d[i]>>p[i];
    }
    if(s==0){//特判一种特殊情况
        puts("0.00");
        return 0;
    }
    d[0]=0;//起点的距离为0
    d[n+1]=s;//终点的距离为s
    p[n+1]=0;//终点的油价为0
    up(i,0,n,1){//检查是否有解
        if(d[i+1]-d[i]>c*l){
			puts("No Solution");
			return 0;            
        }
    }
    ll i,j;
    for(i=0;i<=n;i=j){
        for(j=i+1;j<=n+1;j++){//先找出在当前加油站加满油能到达那些加油站
            if(d[j]-d[i]>c*l){
                j--;//超出了加满油能到达的范围，所以j--，即j指向当前加油站
                break;
            }
            if(p[j]<p[i]) break;//找到第一个比当前油价低的加油站
        }
        double y=(d[j]-d[i])/l;//需要消耗的油量
        if(p[j]<p[i]){//找到更便宜的加油站，只用买够到那个加油站的油
            if(num<y){
                ans+=(y-num)*p[i];//如果当前油量不够，需要先买油
                num=y;
            }
            num-=y;//到达目标加油站后，消耗了y升油
        }
        else{//没有更便宜的加油站，需要买满油，前往可以到达的加油站中油价最低的加油站
            ans+=(c-num)*p[i];//加满油
            num=c;
            num-=y;//到达目标加油站后，消耗了y升油
        }
    }
    cout<<fixed<<setprecision(2)<<ans<<endl;//根据题目要求保留两位小数
    return 0;
}//Sky_distant
