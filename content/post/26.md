## 题目理解

- 第一行两个整数 $P$（$1\le P\le 10^{9}$）和 $C$（$1\le C\le10^{3}$），分别表示公民数量和命令的数量。
- 接下来 $C$ 行，每行一个操作，如果操作是一个 `N`，则表示处理队列中的患者，如果命令是 `E x`，则表示将编号为 `x` 的患者移动到队列最前端。
- 最后输入 `0 0` 表示输入结束。
- 用一个双向队列来处理操作。
- 用一个普通队列来存储答案。

:::warning[注意]
虽然 $1\le P\le 10^{9}$，但 $1\le C\le10^{3}$，只有前 `1000` 个元素会被操作，所以这里可以优化。
:::

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
deque<int> q;
queue<int> ans;
int num=1;
char qwq;
int p,c;
void qclear(){queue<int> b;swap(b,ans);}//清空函数，因为普通队列没有clear函数
void read(){//输出答案
    cout<<"Case "<<num++<<":";
    puts(""); 
    while(!ans.empty()){
        cout<<ans.front();
        puts("");
        ans.pop();
    }
}
int main() {
    cin>>p>>c;
    while(p!=0&&c!=0){
        q.clear();//多测不清空
        qclear();//爆零两行泪
        int awa=min(p,c+1000);
        for(int i=1;i<=awa;i++)q.push_back(i);//初始化原队列
        while(c--){//c次操作
            cin>>qwq;
            if(qwq=='N'){
            	int x=q.front();
                ans.push(x);
                q.pop_front();
                q.push_back(x);
            }else{
                int x;
                cin>>x;
                auto it=find(q.begin(),q.end(),x);
                if(it!=q.end()){
                    q.erase(it);
                }
                q.push_front(x);
            }
        }
        read();
        cin>>p>>c;
    }
    return 0;
}//Sky_distant
