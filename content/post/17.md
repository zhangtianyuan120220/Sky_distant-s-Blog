## 题目分析
- 这道题要求输入两个字符串 $x$ 和 $y$，如果 $x$ 和 $y$ 全是数字，就输出 $x-y$ 的值，否则就输出 `NaN`。
- 解题思路：先用字符串输入，在判断 $x$ 和 $y$ 中有没有字符，有就输出 `NaN`，并同时将字符串 $x$ 和 $y$ 转为整形，最后输出结果。

## 代码实现
```cpp
#include<bits/stdc++.h>
#define ll long long
#define up(l,r) for(int i=l;i<=r;i++)
using namespace std;
string a,b;
int main(){
    cin>>a>>b;
    ll x=0,y=0;
    up(0,a.size()-1){
        if(!(a[i]>='0'&&a[i]<='9')){
            puts("NaN");
            return 0;
        }
        x=x*10+a[i]-'0';
    }
    up(0,b.size()-1){
        if(!(b[i]>='0'&&b[i]<='9')){
            puts("NaN");
            return 0;
        }
        y=y*10+b[i]-'0';
    }
    cout<<x-y<<endl;
    return 0;
}//Sky_distant
