## 题目分析
- 第一行一个整数 $N$ 和一个长度为 $N$ 的字符串 $S$。
- 只有当 $S_i=$ `E` 和 $S_j=$ `G` 并且 $S_k=$ `F` 的情况，$ans$ 的值加一。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n;
    string s;
    cin>>n>>s;
    int ans=0;
    for(int i=0;i<n;i++){
        if(s[i]!='E')continue;
        for(int j=i+1;j<n;j++){
            if(s[j]!='G')continue;
            for(int k=j+1;k<n;k++){
                if(s[k]=='F'){
                    ans++;
                }
            }
        }
    }
    cout<<ans<<endl;
    return 0;
}//Sky_distant
