## 题目分析
1. **字符串遍历**：我们只需要从头到尾遍历一遍字符串 $s$。
2. **格式匹配**：在每一个位置 $i$，检查以 $i$ 开头的连续 4 个字符是否依次为 `k`, `i`, `c`, `k`。
3. **重叠处理**：题目明确提到子串可以**重叠**，直接遍历自然能够符合这种重叠情况，因为每次检查都是独立的。

## 代码实现
```cpp
#include<bits/stdc++.h>
#define ll long long
using namespace std;
string s;
ll ans=0;
int main(){
    cin>>s;
    int n=s.length();
    if(n<4){
        puts("0");
        return 0;
    }
    for(int i=0;i<=n-4;i++){
        if(s[i]=='k'&&s[i+1]=='i'&&s[i+2]=='c'&&s[i+3]=='k'){
            ans++;
        }
    }
    cout<<ans<<endl;
    return 0;
}//Sky_distant
