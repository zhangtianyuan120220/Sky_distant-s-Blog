## 题目分析
- 有一个 $n \times m$ 的矩阵，其中只有 0（白巧克力）或 1（黑巧克力），题目要求我们将它切割，切出来的每一块只能是单一颜色的，并且一刀切到底。
- 这道题可以用贪心的思路来做：
  - 我们可以遍历相邻的两列，若颜色不同，就将竖着切一刀，若颜色相同，就继续遍历。
  - 相邻的两行也是一样，颜色不同就横着切一刀，颜色相同，就继续遍历。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,m;
int ans=0;
int main(){
    cin>>n>>m;
    vector<string> a(n);
    for(int i=0;i<n;i++){
        cin>>a[i];
    }
    for(int i=0;i<n-1;i++){
        for(int j=0;j<m;j++){
            if(a[i][j]!=a[i+1][j]){
                ans++;
                break; 
            }
        }
    }
    for(int j=0;j<m-1;j++){
        for(int i=0;i<n;i++){
            if(a[i][j]!=a[i][j+1]){
                ans++;
                break;
            }
        }
    }
    cout<<ans<<endl;
    return 0;
}//Sky_distant
