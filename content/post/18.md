## 题目分析
- 根据题目，可以知道他要我们求一个数的因数之和。
- 我们可以先提前处理每个数的因数和，将储存到 `sum` 数组中。
- 之后直接访问就能直接输出结果了。

## 代码解决
```cpp
#include<bits/stdc++.h>
#define upi(l,r) for(int i=l;i<=r;++i)
using namespace std;
const int N=1000005;
int T;
int sum[N+1];
void num(){
    upi(1,N/2){
        for(int j=2*i;j<=N;j+=i){
            sum[j]+=i;
        }
    }
}
int main(){
    num();
    cin>>T;
    while(T--){
        int n;
        cin>>n;
        if(sum[n]>n){
            puts("abundant");
        }
        else if(sum[n]<n){
            puts("deficient");
        }
        else{
            puts("perfect");
        }
    }
    return 0;
}//Sky_distant
