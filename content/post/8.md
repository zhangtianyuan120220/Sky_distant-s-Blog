## 题目分析
- 先给你一个 $n$，代表有 $n$ 台测谎仪，其中第 $i$ 台测谎仪报告 $i-1$ 台测谎仪所报告的真假，其中最后一台测谎仪所报告的一定是真，求第一台测谎仪所报告的真假。
- 这道题可以使用栈来存储每个测谎仪的报告，之后再一个一个出栈，直到最后一个元素，对于每个栈顶元素，如果是 `LIE` 就将下一个元素反转，最后一个元素就是答案了。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n;
string a;
stack<bool> s;
int main(){
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>a;
        if(a=="TRUTH"){
            s.push(1);
        }
        else{
            s.push(0);
        }
    }
    while(s.size()>1){
        bool awa=s.top();
        s.pop();
        if(awa==0){
            bool qwq=s.top();
            s.pop();
            s.push(!qwq);
        }
    }
    if(s.top()==1){
        puts("TRUTH");
    }
    else{
        puts("LIE");
    }
    return 0;
}//Sky_distant
