## 题目分析
- $S_n$ 是每位都是 `1` 的 $n$ 位数：

$$
S_n = \underbrace{ 11 \ldots 1 }_{ n \text{个}} = \frac{ 10 ^ n - 1 }{ 9 }
$$

- 题目要求计算 $S_n^2$ 的各位数字之和。

## 公式
- 通过一系列的推导就可以得出一个公式。

- 设 $n = 9k + r$，其中 $k = \lfloor n/9 \rfloor$，$r = n \bmod 9$（$0 \le r < 9$）。

- 则 $S_n^2$ 的数字和为：

$$
\text{sum}(n) = 81k + r^2
$$

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
long long n;
int main(){
	while(cin>>n){
		if(n<=9){
			cout<<n*n<<'\n';
		}
		else{
			long long k=n/9;
            long long r=n-9*k;
            cout<<81*k+r*r<<'\n';
		}
	}
	return 0;
}//Sky_distant
