## 思路

### 题目理解
- 有一个长度为 $n$ 数组 $p$。
- 有个人将数组 $p$ 中的起始为 $l$ 终止为 $r$ 的区间内的所有数都加一，得到新数组 $a$。

### 交互过程
- 你可以进行一次查询，每次可以选择两个整数 $l,r$，并查询原始排列 $p_{l\dots r}$ 的子数组和，或修改后数组 $a_{l\dots r}$ 的子数组和。对于该查询，系统会返回对应的整数和，且查询次数不超过 **40** 次。
- 通过查询修改后数组的子数组和减去原始排列可以得到当前区间内被修改的元素数量。
- 利用上述性质，可以二分查找被修改的元素数量。

### 解题思路
- 二分查找被修改的元素数量。
- 每次二分查找时，查询区间 $[l,r]$ 内被修改的元素数量。
- 如果被修改的元素数量大于等于 $mid$，则说明 $r$ 可以向左移动，否则 $l$ 向右移动。

## 代码解决
```cpp
#include <bits/stdc++.h>
using namespace std;
int t,n;
int jh(int l,int r){//与程序交互计算区间内被更改的个数
    int awa,qwq;
    cout<<1<<" "<<l<<" "<<r<<endl;
    cin>>awa;
    cout<<2<<" "<<l<<" "<<r<<endl;
    cin>>qwq;
    return qwq-awa;
}
int main(){
    cin>>t;
    while(t--){
        cin>>n;
        int len=jh(1,n);//更改的区间长度
        int L=1,R=n;
        while(L<R){//二分查找
            int mid=(L+R)/2;
            bool cmp=jh(1,mid);//计算当前区间是否被更改
            if(!cmp){
                L=mid+1;//当前区间没有被更改，则左边界右移
            }
            else{
                R=mid;//当前区间被更改，则右边界左移
            }
        }
        cout<<"! "<<L<<" "<<L+len-1<<endl;//输出答案
    }
    return 0;
}//Sky_distant
