## 题目分析
- 题目说了一大堆，有用的信息有两个：
  - **D2 的（6）**：对剩余的每支队伍重新计算其排名。设 $R$ 为某支队伍的重新计算排名，$S$ 为该场比赛的站点得分。为该排名中的每支队伍分配以下数值：$(R-1)/S$。
  - **D3 的（1）**：按上述分配数值的升序对合并后的列表排序，即数值越小，越有可能晋级。
- 题目要求我们计算两个数值，一个是桃园站的数值，一个是雅加达站的数值：
  - 桃园站的数值为：$V_T=(R_T-1)/S_T$。
  - 雅加达站的数值为：$V_J=(R_J-1)/S_J$。
- 按照题目要求，按照以下规则输出答案：
  - 如果 $V_T<V_J$，输出 `TAOYUAN`。
  - 如果 $V_T>V_J$，输出 `JAKARTA`。
  - 如果 $V_T=V_J$，输出 `SAME`。
- 注意：在浮点型的乘除中，存在精度问题，所以我们需要使用 epsilon 来处理浮点数的精度问题。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
const double eps=1e-9;
double rt,rj;
double st,sj;
double vt,vj;
int main(){
    cin>>rt>>rj>>st>>sj;
    vt=(rt-1.0)/st;
    vj=(rj-1.0)/sj;
    if(vt<vj-eps){
        puts("TAOYUAN");
    }
    else if(vj<vt-eps){
        puts("JAKARTA");
    }
    else{
        puts("SAME");
    }
    return 0;
}//Sky_distant
