## 题目分析
- 一道很简单的模拟题，将每个仓库中每个位置维度的值存入一个二维数组进行比较。
- 题目定义的一个**上级仓库**，就是位置编码的每一维均大于当前仓库的对应的位置编码维度值。
- 题目要求输出当前仓库的上级仓库，若有多个，取最小的，没有的话输出 0。

## 代码实现
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,m;
int main(){
    cin>>n>>m;
    vector<vector<int> > a(n+1,vector<int>(m));
    for(int i=1;i<=n;i++){
        for(int j=0;j<m;j++){
            cin>>a[i][j];
        }
    }
    for(int i=1;i<=n;i++){
        int num=0;
        for(int j=1;j<=n;j++){
            if(i==j)continue;
            bool cmp=1;
            for(int k=0;k<m;k++){
                if(a[j][k]<=a[i][k]){
                    cmp=0;
                    break;
                }
            }
            if(cmp){
                num=j;
                break; 
            }
        }
        cout<<num<<endl;
    }
    return 0;
}//Sky_distant
